Privacy Policy

How the public website and public MCP documentation tools process information.

Scope

The public website does not require account registration. The submitted ChatGPT app exposes a read-only MCP server that searches and retrieves only approved public website pages and public documentation.

Information processed by the MCP server

When a tool is used, the server may process the selected tool name, its public-document search query or page path, an MCP session identifier, request timing, HTTP status, and the public content returned by the tool.

Information not intentionally collected

  • No payment information or customer account credentials are collected by this public app.
  • No private repository contents, unpublished research, raw protected OpenQASM, private IBM Quantum job payloads, or API credentials are exposed.
  • No application database stores tool requests or ChatGPT conversation history.
  • No tracking scripts or advertising cookies are included by default.

Operational logs

The MCP service may produce limited operational logs for startup, readiness, request status, duration, and errors. The application does not intentionally log full tool arguments or returned document bodies. The hosting provider may retain standard network and access logs under its own policies and configuration.

Storage and retention

MCP sessions are held in process memory and are removed when a transport closes or the service restarts. The submitted public app has no persistent application database.

Service providers

OpenAI transports app tool requests from ChatGPT. The selected application host runs the MCP server and may process network metadata. Static website hosting may be provided separately. The submitted read-only app does not execute IBM Quantum jobs.

Your choices

Do not include personal, confidential, or unpublished information in public-document search queries. Privacy questions and deletion requests concerning information sent directly through support channels can be submitted through the published contact page.

Future features

Authentication, paid services, persistent customer accounts, private research access, or quantum job submission would require a separate privacy review and an updated policy before release.
